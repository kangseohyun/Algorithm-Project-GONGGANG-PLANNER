# 기능 및 통합 실행 검증 보고서

- 검증일: 2026-06-18
- 환경: macOS, Python 3.12.4
- 의존성: folium 0.20.0, pandas 2.3.3, Pillow 7.1.0 이상 11 미만, streamlit 1.32.0
- 최종 판정: 정상 작동

## 개별 기능 검증

| 기능 | 실행 방법 | 결과 |
|---|---|---|
| 시간표/공강 분석 | `python timetable_analyzer.py` | PASS: 공강, 수업 중, 수업 전, 수업 후, 수업 없음 5개 케이스 정상 |
| 최단경로 | `python path_finder.py` | PASS: 다익스트라 계산, 경로 복원, 이동시간 정렬 정상 |
| 혼잡도/대기시간 | `python crowd_analyzer.py` | PASS: 시간대 탐색, 혼잡도, 대기시간, 기본값 처리 정상 |
| 장소 추천 | 통합 assertion 테스트 | PASS: 30개 후보 계산 후 상위 3개 추천 생성 |
| 경로 시각화 | `python path_visualizer.py` | PASS: `campus_path.html` 생성 정상 |
| Python 문법/임포트 | `python -m compileall -q .` | PASS |

## 통합 실행 검증

CLI `python main.py` 입력:

- 요일: 수
- 시간: 10:30
- 현재 위치: 가천관
- 목적: 공부

주요 결과:

- 공강 150분, 추천 계산 기준 140분
- 다음 수업: 운영체제 13:00, 글로벌센터
- 추천 후보 30개, 경로 노드 결과 14개, 최종 추천 3개
- 1위: 가천관 아르테크네 / 라곰스페이스, 89점
- 최적 이동경로 4분
- `campus_path.html` 생성 성공

Streamlit 브라우저 검증:

- 메인 시간표 표시: PASS
- 입력 컨트롤 표시: PASS
- `추천 계산` 버튼 실행: PASS
- 공강 요약, 지도, 추천 3개 카드 표시: PASS
- 서버 런타임 예외: 없음

## 검증 중 수정한 문제

1. Streamlit 1.32에서 `st.columns(..., gap=None)`이 예외를 발생시켜 `gap="small"`로 수정했습니다.
2. CLI 통합 실행이 지도 생성 후 브라우저를 강제로 열며 macOS 자동화 오류를 내던 부분을 `open_browser=False` 기본값으로 수정했습니다.
